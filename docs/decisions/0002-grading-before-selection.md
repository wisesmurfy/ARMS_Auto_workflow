# ADR-0002: 근거 등급화는 사람이 고르기 전에 둔다 (A2.5)

- 상태: Accepted (등급화 구현은 v1 범위 밖)
- 날짜: 2026-10-03

## 배경
- A2가 구성안 3개를 만들고, A3에서 사람이 1개를 고른다
- 구성안마다 뒷받침할 문헌의 양과 질이 다를 수 있다
- 고른 뒤에 근거가 약하다는 걸 알면 처음부터 다시 골라야 한다

## 결정
- A/B/C 근거 등급화 단계를 A2와 A3 사이(A2.5)에 둔다
- v1에서는 구현하지 않고 자리만 둔다: 각 Option의 `grade`는 `None`

## 결과
- 좋은 점: 나중에 등급화를 넣을 때 파이프라인 순서와 스키마를 바꾸지 않아도 된다
- 감수할 점: v1에서는 사람이 근거 강도 정보 없이 구성안을 고른다
- 다시 볼 조건: 모듈 B(PubMed 검색)가 생겨 실제 문헌으로 등급을 매길 수 있을 때 구현한다
