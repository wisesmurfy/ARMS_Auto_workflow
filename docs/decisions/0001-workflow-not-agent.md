# ADR-0001: Agent가 아니라 Workflow로 만든다

- 상태: Accepted
- 날짜: 2026-10-03

## 배경
- LLM 앱은 두 가지로 만들 수 있다 (Anthropic, *Building effective agents*, 2024).
  - Workflow: 코드가 순서를 정하고 LLM은 각 칸을 채운다
  - Agent: LLM이 다음 행동을 스스로 정한다
- 학술팀 가이드라인은 순서가 이미 정해져 있다: 분석 → 구성안 → 선택 → 검색 → 선별 → 작성
- 의학 근거는 재현성과 감사 가능성(누가 어떤 근거로 골랐는지 나중에 확인)이 핵심이다

## 결정
- 순서는 `pipeline.py`가 코드로 고정한다. LLM이 다음 단계를 고르지 않는다
- 패턴: Prompt chaining + Gate(사람 선택) + Tool-based Retrieval(PubMed, 모듈 B부터)

## 결과
- 좋은 점: 매 실행이 같은 경로를 지나 결과를 비교·검증하기 쉽다. 디버깅이 쉽다
- 감수할 점: 예상 밖의 주제에 LLM이 스스로 대응하는 유연성은 없다
- 다시 볼 조건: 가이드라인 순서로 처리할 수 없는 경우가 반복될 때만 자율성을 올린다
