# ADR-0003: 문헌 검색은 PubMed만 쓴다 (v1)

- 상태: Accepted
- 날짜: 2026-10-03

## 배경
- 의학 문헌 데이터베이스로 PubMed와 Embase 등이 있다
- PubMed는 NCBI E-utilities로 누구나 무료로 프로그램에서 검색할 수 있다
- Embase는 유료 구독이 필요하다

## 결정
- v1의 모듈 B는 PubMed(E-utilities)만 검색한다. Embase는 하지 않는다

## 결과
- 좋은 점: 비용·계정 없이 누구나 실행하고 결과를 재현할 수 있다
- 감수할 점: PubMed에 없는 문헌(일부 유럽 저널, 학회 초록 등)은 빠질 수 있다.
  이 도구의 결과는 정식 체계적 문헌고찰을 대신하지 않는다
- 다시 볼 조건: Embase 접근 권한이 생기고 누락이 실제 문제로 확인될 때
