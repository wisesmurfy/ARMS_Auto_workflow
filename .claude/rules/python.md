# Python 규칙

## 코드
- 타입 힌트 필수. 데이터 모양은 Pydantic v2 모델로 정의한다
- 함수는 작게, 하나의 변환만. print 대신 logging
- 네트워크 호출은 `llm.py`(나중에 `pubmed_client.py`)에서만
- LLM 출력을 `eval`·`exec`·셸로 실행하지 않는다

## 주석 (문법을 몰라도 데이터 흐름이 보이게)
1. 파일 맨 위 = 이 파일의 지도: 파이프라인 위치, 들어오는 것, 나가는 것, 작은 그림
2. 함수 설명 = Google 스타일 `Args / Returns / Raises`
3. 데이터가 바뀌는 줄 = 모양 주석. 예) `# str → TopicFrame{P, EI, C, O}`
4. "왜"는 근거 번호로. 예) `# 가이드라인 2항`, `# ADR-0002`. 코드를 다시 읽어주는 주석은 쓰지 않는다
- 주석은 한국어, 이름(변수·함수)은 영어
- 코드를 바꾸면 어긋난 주석도 같이 고친다
